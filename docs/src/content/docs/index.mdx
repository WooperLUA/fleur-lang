## Why Fleur?

<CardGrid>
	<Card title="Easy to learn" icon="pencil">
		Clean syntax inspired by modern languages, making it easy for beginners to learn but familiar enough for veterans.
	</Card>
	<Card title="Basic Data Structures" icon="document">
		Rich support for Arrays, Sets, Maps, and Structs out of the box.
	</Card>
	<Card title="Simple yet effective" icon="add-document">
		Flexible programming paradigms with functions, procedures, and struct methods to implement whatever you need.
	</Card>
	<Card title="Easy types for an easy time" icon="setting">
		Weakly typed with explicit casting to learn about types without having to rely on type hinting.
	</Card>
</CardGrid>
