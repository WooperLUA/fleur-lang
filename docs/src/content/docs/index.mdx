## Why Fleur?

<CardGrid>
    <Card title="Intuitive Syntax" icon="pencil">
        A clean, minimalist design that strips away boilerplate while keeping it explicit. Approachable for newcomers, yet highly expressive for seasoned developers.
    </Card>
    <Card title="Powerful Data Structures" icon="database">
        Rich, built-in support for Arrays, Sets, Maps, and Structs, featuring deep equality and deep immutability out of the box.
    </Card>
    <Card title="Intentional Paradigms" icon="code">
        Write predictable code with distinct <code>func</code>tions for pure logic and <code>proc</code>edures for side-effects.
    </Card>
    <Card title="Pragmatic Typing" icon="shield">
        Start dynamically typed for rapid prototyping, then seamlessly layer on optional type annotations and generics when you need runtime safety.
    </Card>
</CardGrid>
